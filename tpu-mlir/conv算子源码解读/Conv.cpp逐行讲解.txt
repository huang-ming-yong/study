Conv.cpp 逐行讲解 —— 以 Conv1dTo2d 为例
========================================================================

场景：ONNX 里有 1D 卷积，但 BM1684X 只支持 2D 卷积。
      这个 Pass 就是把 1D 卷积伪造成 2D 卷积 —— 在 kernel 末尾补一维 1。

比如 kernel_shape 原来 = [3]，改成 [3, 1]，板子就能跑了。

完整的骨架结构（所有规则都一样）
========================================================================

  struct XxxPattern : public OpRewritePatternEx<ConvOp> {     // 1. 定义一个规则
    matchAndRewriteImpl(ConvOp op, PatternRewriter &rewriter) {
      // 2. 检查：是不是我要处理的场景？（不是 → return failure()）
      // 3. 动手：修改算子的属性/输入/输出
      // 4. return success()
    }
  };

========================================================================
用你已经看过的 .mlir 来理解
========================================================================

改写前（1D Conv）：
  %3 = "top.Conv"(%0, %1, %2) {
    kernel_shape = [3],      ← 1 维
    strides = [2],
    pads = [1, 1]
  } ...

改写后（伪造成 2D Conv）：
  %3 = "top.Conv"(%0, %1, %2) {
    kernel_shape = [3, 1],   ← 补成了 2 维
    strides = [2, 1],
    pads = [1, 0, 1, 0]      ← 4 个数，标准的 2D padding
  } ...

板子看到的就是标准 2D 卷积了，虽然有一维大小是 1（等于空转），但能跑。


========================================================================
对比：Toy Tutorial 的骨架 vs Conv.cpp 的实际代码
========================================================================

  Toy Tutorial（简化）:
    struct SimplifyRedundantTranspose : public OpRewritePattern<TransposeOp> {
      matchAndRewrite(TransposeOp op, ...) {
        if (不是我要的 pattern) return failure();
        修改 op
        return success();
      }
    };

  Conv.cpp（实际代码）:
    struct Conv1dTo2d : public OpRewritePatternEx<ConvOp> {
      matchAndRewriteImpl(ConvOp op, ...) {
        if (kernel->size() != 1) return failure();    ← 不是 1D → 不管
        修改 kernel/strides/pads/dilations             ← 全补一维
        return success();
      }
    };

  区别只有两点:
    1. 基类名：OpRewritePattern  →  OpRewriterPatternEx（tpu-mlir 自己包装的）
    2. 函数名：matchAndRewrite   →  matchAndRewriteImpl

  其余思路完全一样："匹配条件 → 不满足就跳过 → 满足就修改 → 返回成功"。


========================================================================
Conv.cpp 文件底部的注册行（第 673 行）
========================================================================

  void ConvOp::getCanonicalizationPatterns(RewritePatternSet &results,
                                           MLIRContext *context) {
    results.insert<Conv3dTranspose, Conv3dTo2d, Conv1dTo2d,
                   Conv1x1Convkxk2dMerge, ConvReshapeSlicePattern>(context);
  }

  这一行的意思是："把这些规则全部注册到 Canonicalization 框架里。"
  框架会在 IR 上反复扫描，每碰到一个 Conv 算子就挨个试这些规则，
  直到 IR 不再变化为止。
